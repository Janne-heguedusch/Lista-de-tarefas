# Lista de Tarefas (HTML + JS)
Projeto simples do curso Técnico em Informática. Uma lista de tarefas que salva no navegador (localStorage).

## Como usar
- Abra `index.html` no navegador (duplo clique) **ou**
- Acesse a versão online (GitHub Pages): [(https://github.com/Janne-heguedusch/Lista-de-tarefas/new/main?filename=README.md)](https://github.com/Janne-heguedusch/Lista-de-tarefas)

## Funcionalidades
- Adicionar tarefas
- Marcar como concluída
- Excluir
- Salva automaticamente (localStorage)
